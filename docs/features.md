# Features

## Must have (core)
1. Add a transaction: amount, type (income/expense), category, date, payment method, optional note
2. View all transactions for a selected month
3. Edit an existing transaction
4. Delete a transaction (with confirmation)
5. Monthly summary: total income, total expense, balance
6. Expense breakdown by category

## Visualization
7. Doughnut chart: expense by category
8. Bar chart: income vs expense

## Quality
9. Client-side form validation with error messages under each field
10. Server-side validation with proper status codes (400, 404, 500)
11. Loading spinner, error banner, and empty state
12. Responsive layout (mobile, tablet, desktop)

## Out of scope (not building)
- User login / authentication
- Multiple currencies
- Recurring transactions
- Export to CSV

## Categories
- Expense: Food, Transport, Rent, Shopping, Bills, Health, Entertainment, Other
- Income: Salary, Freelance, Gift, Other

## Payment methods
Cash, Card, UPI, Bank
